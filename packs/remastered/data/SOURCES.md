# Sources for the remastered data files

## Word lists (`waves.txt`, `twords.txt`)

Generated by `tools/gen-words.mjs` (run `node tools/gen-words.mjs`; it downloads the
sources below into a temporary cache directory and rewrites both files; output is
deterministic). No word list from the original game was used.

How the lists are built:

- A word must be lowercase a-z in all three sources: in ENABLE, in SCOWL's
  `english-words`/`american-words` lists at size level 50 or below (these lists exclude
  proper names, abbreviations and contractions), and in the 12dicts frequency list.
- Commonness: 12dicts `2+2+3frq` groups words into 21 frequency bands. Enemy words of
  4-7 letters must be in bands 1-17; 3-letter words may come from any band, plus a short
  hand-picked list of everyday words/interjections (`EXTRA` in the script).
- Family-friendly filter: an exact-word blocklist (with simple inflections) and a
  substring blocklist remove profanity, slurs, sexual and anatomical terms, violence,
  weapons, death, drugs/alcohol/tobacco, gambling, bodily functions, disease, insults and
  religious/political terms; an `OBSCURE` list removes archaic, technical and
  abbreviation-like words. An allowlist keeps innocent words that contain a blocked
  substring (e.g. SHELL, SKILL, NUMBER).
- `waves.txt`: `#LENGTH-3` .. `#LENGTH-7`, words grouped by exact length
  (504 / 1475 / 2054 / 2903 / 3127 words).
- `twords.txt`: `#DIFF-3` .. `#DIFF-21`, DIFF = sum of letter values (A D E F G H J K L S
  = 1; B I M N R T U V Y = 2; C O P Q W X Z = 3), words of 3-19 letters, at most 1000 per
  bucket preferring the most frequent words (DIFF-3: 37, DIFF-4: 169, DIFF-5: 416,
  DIFF-6: 722, DIFF-7..19: ~1000 each, DIFF-20: 891, DIFF-21: 691).

## Other content

All other data files in this directory were written from scratch for this project; no
text, names or numbers were copied from the original game's data files (only their file
formats are reused so the game code can read either pack):

- `easy-cfg.xml`, `normal-cfg.xml`, `hard-cfg.xml`, `expert-cfg.xml`, `xtreme-cfg.xml`,
  `abyss.xml`: generated by `tools/gen-configs.mjs` from an original level design (enemy
  line-up per level, speeds, word lengths, counts, penalties, treasure difficulty).
- `themes.txt`: original themed word lists (common English words and general-knowledge
  names such as planets, countries and cities).
- `shipnames.txt`, `gemnames.txt`: original fictional names.
- `Lesson0.xml` .. `Lesson18.xml`: original typing-tutor lessons and drills.
